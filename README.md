One original pickup line a vending machine would use on a passing human (75 characters):

> You must be the last bag of crisps, because I've been stuck on you all day.

The setup is the machine's own world — the last bag of crisps, the one every vending machine leaves dangling in its coil. The punch turns on "stuck on you": stuck in the coil, and smitten. One sentence, no filler, the double meaning lands on the last three words.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
